# Доска флота агентов

Источник правды по смыслу задач, которые выполняют фоновые сессии Claude Code.

## Что здесь есть

- `cards/` — по одному файлу на задачу, имя `YYYY-MM-DD-slug.md`.
- `archive/AGENTS-ARCHIVE.md` — реестр снесённых сессий.
- `scripts/validate_cards.py` — проверка схемы карточек.

Видов доска не хранит: срезы «в работе», «на ревью» и «всё» рисует пульт
fleetdeck, читая эти же карточки.

Регламент работы с доской лежит не здесь, а в плагине `agent-fleet`:
скил `fleet-orchestrator` — для того, кто раздаёт задачи, скил
`card-keeping` — для агента, который ведёт свою карточку.

## Чего здесь нет намеренно

Состояния сессии: жива ли она, чем занята, запинена ли. Это знает демон
Claude Code, и дублировать его сюда нельзя — иначе появится второй источник
правды, который начнёт врать. Живое состояние смотрят через `list_sessions`
или FleetView.

## Схема карточки

| Поле | Значения | Обязательное |
| --- | --- | --- |
| `zone` | `urgent`, `unplanned`, `planned`, `niceToHave` | да |
| `stage` | `new`, `active`, `review`, `done`, `blocked` | да |
| `progress` | `0`, `10`, `20`, `40`, `60`, `80`, `100` | да |
| `session` | short id фоновой сессии | при `stage: new` нет, дальше да |
| `repo` | путь репозитория относительно домашнего каталога | нет |
| `created` | `YYYY-MM-DD` | да |

Других полей во frontmatter быть не должно: валидатор отвергает незнакомое
поле. Так принцип «одно поле — один источник правды» держится не только на
прозе в скилах.

Конвенция прогресса: `0` заведена · `10` запущен · `20` работает ·
`40` черновик отдан · `60` итерация · `80` почти · `100` готово вместе с
`stage: done`.

## Кто что пишет

До спавна карточку ведёт оркестратор: заводит её в `stage: new`,
`progress: 0`, заполняет `zone`, `created`, `repo`, заголовок и «Контекст»,
поднимает сессию и вписывает её short id в `session` — и только после этого
отправляет агенту задачу. К моменту, когда агент начинает работать, поле
`session` уже на месте.

После спавна карточку ведёт сам агент: `stage`, `progress` и раздел «Лог».
За оркестратором остаётся только раздел «Контекст», куда он доносит новые
вводные от оператора.

## Git

Грязное дерево волта — норма: агенты правят карточки по ходу работы и ничего
не коммитят. Накопленные правки фиксирует одним коммитом оркестратор, когда
оператор просит прибрать флот.

## Проверка

```bash
python3 scripts/validate_cards.py
```

Аргументом можно передать одну карточку — тогда проверяется только она.
Агенту нужен именно этот режим: чужие карточки при живом флоте почти всегда
в промежуточном состоянии, и чинить их он не вправе.

```bash
python3 scripts/validate_cards.py cards/2026-09-05-slug.md
```
