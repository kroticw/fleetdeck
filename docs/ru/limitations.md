# Ограничения

Чего fleetdeck не делает и чего касается на машине, где работает.

## Только macOS

Две вещи вызывают инструменты macOS без запасного варианта: чтение OAuth-токена Anthropic из Keychain — командой `security`, и показ баннеров уведомлений — через `osascript`. Кроссплатформенного аналога ни у того, ни у другого в этой кодовой базе нет.

## Только локальный демон

fleetdeck общается с демоном Claude Code через его Unix-сокет управления на той же машине. Удалённого или сетевого режима нет.

## Доске нужны git и python3

История доски — это git-репозиторий, а валидатор карточек, который запускают агенты, — скрипт на Python. На Mac без Command Line Tools `/usr/bin/git` и `/usr/bin/python3` — заглушки, предлагающие их установить.

Доска создаётся и без них. Но тогда пульт не может закоммитить свои правки карточек, а агенты — проверить свои. `xcode-select --install` даёт и то и другое.

## Что он читает в домашнем каталоге

Три вещи, и больше ничего:

- элемент Keychain с учётными данными OAuth Claude Code;
- markdown-файлы по настроенному пути доски и git-репозиторий, который их содержит;
- файлы транскриптов сессий, которые пишет Claude Code.

## Куда уходят учётные данные

Прочитанный из Keychain OAuth-токен отправляется ровно на один узел, `api.anthropic.com`. Он никогда не логируется, не пишется на диск и не передаётся в браузер.

## Баннер — это не подтверждённая доставка

Единственный сигнал, который есть у fleetdeck, — код возврата `osascript`, а ноль означает, что команда выполнилась, а не что баннер появился. macOS молча гасит уведомления, если доступ не разрешён или включён режим фокусирования, и `osascript` всё равно возвращает ноль.

Доставку на экран здесь ничто не проверяет: для этого пришлось бы читать недокументированную приватную базу. Поэтому не появившийся баннер — не ошибка, о которой fleetdeck может сообщить. Собственные счётчики пульта от всего этого не зависят, и доверять стоит им.

## Инлайновые стили, ради одной библиотеки

Content-Security-Policy пульта — `'self'` везде, кроме `style-src`, где добавлено `'unsafe-inline'`.

Вендоренный xterm.js создаёт элементы `<style>` во время работы и заполняет их измеренным размером ячейки терминала и цветами темы, а в этой версии библиотеки опции nonce нет. Без этого ключевого слова терминал рисуется пропорциональным шрифтом и без цвета.

`script-src` и `default-src` остаются `'self'`, поэтому разрешён подставленный внешний вид, а не подставленное поведение. См. комментарий к `contentSecurityPolicy` в `internal/server/static.go`.
